# Panoleon 操作マニュアル

本書は利用者向けの操作手順である。**アプリのインストール**と**開発環境の構築**の違い・全体像は [インストールと環境構築.md](インストールと環境構築.md) を参照する。MSIX・証明書の詳細は [社内配布手順.md](社内配布手順.md) を参照する。

---

## 1. このアプリでできること

- 指定したフォルダ（ローカルドライブや UNC ネットワークパス）内のファイルを、**キーワードで全文検索**する。
- **検索前から**フォルダツリーを閲覧し、ファイルを選ぶと**本文プレビュー**（テキスト抽出）を表示する。
- あらかじめ**インデックス**（検索用データ）を作成・更新する。初回利用前、またはファイルが増減したあとに実行する。

---

## 2. 起動

- **開発・デバッグ**: リポジトリの `src/FileSearch.Blazor` で `dotnet run`（環境により `-f net8.0-windows10.0.19041.0` 等が必要な場合あり）。
- **配布パッケージ**: MSIX 等でインストールした場合は、スタートメニューなどから「Panoleon」を起動する。

ウィンドウタイトルは **Panoleon v2.0** と表示される。起動時はテーマに合わせたスプラッシュが最低約 3 秒表示される。

---

## 3. 画面の構成

| 領域 | 内容 |
|------|------|
| **サイドバー上部** | 「検索結果」見出し、設定ボタン（歯車アイコン） |
| **左サイドバー** | 検索モード（AND / OR / 完全一致）・検索欄・**検索**ボタン・フォルダツリー（検索前閲覧可）・フッター（インデックス状態・再構築） |
| **右メイン** | フォルダを選んでいるときは**一覧表**（名前・内容・更新日時）、ファイルを選んでいるときは**プレビュー**、未選択時は案内メッセージ |
| **サイドバー幅** | 右端の細い境界をドラッグして変更可能 |

---

## 4. 初回の流れ（必須）

### 4.1 検索対象フォルダを登録する

1. サイドバー上部の **設定** を開く。
2. **検索対象フォルダ** で **＋（フォルダ追加）アイコン** を押し、OS のフォルダ選択ダイアログから選ぶ（UNC パスも選択可能な場合がある）。パスの手入力欄はない。
3. 不要な行は一覧横の **×** で削除できる（管理者モードのみ）。
4. 画面下部の **保存** を押す。

> **ヒント**: 対象拡張子を空にすると、あらかじめアプリが対応している拡張子（テキスト・Office・PDF・.msg 等）が使われる。絞り込みたいときだけチップから `.txt` 等を選ぶ。

### 4.2 インデックスを作成する

検索するには、対象ファイルの内容を読み取った **インデックス** が必要である。

1. メイン画面左下フッターの **再構築** を押す。
2. **インデックスの更新** ダイアログで、初回は **全体を再構築** を選び **実行** を押す。
3. 進捗がフッターに表示される。長時間かかる場合がある。
4. 完了すると「最終更新」の表示が変わる。

**差分更新** は、すでにインデックスがあり、追加・変更・削除だけ反映したいときに使う（速い）。

---

## 5. 検索の操作

1. 左の **キーワードを入力…** に語句を入力する。
2. **検索** ボタンを押すか **Enter** で検索を実行する（入力のたびに自動検索はしない）。
3. 検索モード（**AND検索** / **OR検索** / **完全一致検索**）をラジオで切り替えられる。キーワードがある状態でモードを変えると自動で再検索する。
4. 検索中はツリー領域にスピナーと **`（n/N 件）`** の進捗が表示され、その下に **フォルダ階層のツリー** が並ぶ（件数バッジは表示しない）。

### 5.1 ツリーまわりの表示

| 表示 | 意味 |
|------|------|
| 検索キーワードを入力 | まだ検索していない（または空） |
| Enter で検索 | キーワードはあるが Enter / 検索ボタン未実行 |
| 結果なし | 検索済みで 0 件 |
| 検索中... | 検索処理中 |

### 5.2 インデックス構築中

- **再構築中は検索できません** と出て検索欄が無効になる。完了まで待つか、**キャンセル** で中断できる。

### 5.3 キー操作（検索欄にフォーカスがあるとき）

| キー | 動作 |
|------|------|
| **Enter** | 検索を実行 |
| **Esc** | 検索語をクリア（結果ツリーはそのまま残る場合がある） |

### 5.4 領域別の拡大／縮小（ズーム）

| 操作 | 動作 |
|------|------|
| **左サイドバー上で Ctrl + マウスホイール** | サイドバー（検索結果ツリー側）のみ拡大／縮小 |
| **右メイン上で Ctrl + マウスホイール** | 右メイン（プレビューやフォルダ一覧）のみ拡大／縮小 |
| **Ctrl + 0** | カーソル／フォーカスのある側だけ等倍に戻す |

- 倍率は 0.5〜3.0 倍の範囲（10% 刻み）。
- 倍率は **保存されない**。アプリを再起動すると、両側とも等倍に戻る。

## 6. 結果の見方とプレビュー

### 6.1 フォルダを開く

- ツリーで **フォルダ名** をクリックすると、そのフォルダが展開され、右側に **ファイル一覧表**（**名前・内容・更新日時**）が出る。
- 列幅はヘッダ境界をドラッグしてエクスプローラー式に変更できる。
- 列ヘッダでソート、種類でフィルターできる。
- **親フォルダへ戻る** で階層を上がれる。

### 6.2 ファイルを開く（プレビュー）

- ツリーで **ファイル** をクリックすると、右側に **抽出テキストのプレビュー** が表示される（Word / Excel / PowerPoint / PDF / .msg もテキストとして表示。表やレイアウトそのものは再現しない）。
- 検索語に一致する箇所は強調表示される。
- **前へ / 次へ** で一致行の移動、**ファイルを開く** で既定アプリ起動、**フォルダを開く** でエクスプローラーでそのファイルの場所を開く。

### 6.3 ファイル未選択時

右側に「**ファイルを選択**」「左側のツリーからファイルをクリック」と表示される。

## 7. インデックスの更新

| 操作 | 手順 |
|------|------|
| **更新ダイアログを開く** | フッター **再構築** |
| **差分更新** | 追加・変更・削除されたファイルのみ反映（通常はこちらが速い） |
| **全体を再構築** | 対象フォルダを全件スキャンし直す（初回や不整合が疑われるとき） |
| **実行中の中断** | フッター **キャンセル** |
| **完了後にスキップがあった場合** | フッターに「N 件がスキップされました」と出る。その行をクリックするとスキップログ（`skipped_files.log`）が開く |

### 7.1 スキップとログ

次のような場合、当該ファイルは本文インデックスから除外され、一覧に **スキップ** として数えられることがある。

- ファイルサイズが **1MB を超える**（本文抽出しない）
- 抽出エラー（破損、権限、その他）

スキップしたファイルのパス一覧は、インデックス保存先の `skipped_files.log` に出力される（UI ではパスは表示せず、フッターの警告行をクリックして開く）。

### 7.2 自動更新（定期差分更新）

設定の **自動更新** で「毎日、指定した時刻に差分更新する」を有効にし、**日本標準時 0〜23 時**のグリッドから時刻を選ぶと、指定枠を過ぎたときに **差分更新** が自動で走る（時刻未選択で無効）。管理者 PC のみ実行され、利用者の検索中は見送られる。

---

## 8. 設定の項目（概要）

| 項目 | 説明 |
|------|------|
| **テーマ** | ダーク / ライト / システムに従う |
| **検索対象フォルダ** | フォルダピッカー（＋アイコン）で追加。手入力なし |
| **対象拡張子** | チップで選択。空なら既定の対応拡張子。変更後は **保存** のあと **差分更新** または **全体を再構築** が必要 |
| **インデックス保存先** | Lucene インデックスを置くフォルダ（1 つ）。フォルダ選択アイコンのみ。変更後は再構築が必要 |
| **最終更新・自動更新** | 状態確認と JST 時刻グリッドによる自動差分更新 |

**保存** で `settings.json` に保存され、管理者の場合は `shared.json` にも `indexPath` / `targetFolders` が書き込まれる。**キャンセル** や × で閉じた場合は未保存の変更は破棄される。

---

## 9. 注意事項（制限）

| 項目 | 内容 |
|------|------|
| 大きなファイル | **1MB 超** は本文インデックス・プレビュー対象外（スキップ／エラー表示） |
| 1MB 以下 | 抽出した本文を**全文**検索・プレビュー（文字数での打ち切りなし） |
| 形態素解析 | 内部で Sudachi ネイティブ DLL（`sudachi_ffi.dll`）を使用。Python は不要 |
| 共有インデックス | 利用者（参照専用）モードでは再構築・フォルダ変更は不可。設定変更は管理者の保存後、再起動または 60 秒以内の自動同期で反映 |
