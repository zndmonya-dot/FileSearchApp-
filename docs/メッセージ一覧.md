# メッセージ一覧（エラー・警告・情報）

ユーザー向けに画面やログに表示される文言を分類して一覧化する。文言変更・多言語化・テスト設計の参照用。

**コード上の所在**

- **画面 UI**: `src/FileSearch.Messages/UserMessages.cs`（`net8.0` の専用プロジェクト。`FileSearch.Blazor` および単体テストから参照）。クラス XML コメントの `<remarks>` に保守上の注意あり。
- **インデックス・スキップログ**: `src/FullTextSearch.Core/IndexMessages.cs`
- **メイン画面の分割**: `src/FileSearch.Blazor/Components/Pages/Home.razor.cs` および各 `Home.*.cs` に、ファイル先頭の役割説明に加え、主要なフィールド（グループ単位）・メソッドに XML コメント（`///`）を付与。
- **共有 UI・ルート**: `Components/Shared/*.razor` の `@code` に `///`、先頭に役割の `@* ... *@`。`Routes.razor` / `Layout/MainLayout.razor` / `Pages/Home.razor` の先頭にも同様の役割コメント。
- **Core / Infrastructure / Messages / テスト**: 各 `.cs` にファイル先頭の `//` 役割コメント（または既存の分割説明）、公開 API・主要メンバーに `///`。`UserMessages` は定数・メソッドごとに要約。`LuceneIndexService` / `LuceneSearchService` は private ヘルパーにも `///` を付与。`Sudachi/SudachiTokenizer.cs` はインスタンス／静的メンバーと既存の調査メモを併記。

**凡例**

| 分類 | 意味 |
|------|------|
| **エラー** | 操作の失敗や致命的な問題を示す（バナー・フッター赤字・`[エラー]` 接頭辞など） |
| **警告** | 続行可能だが注意が必要（設定バリデーションの黄枠・スキップ件数・インデックス中の制限など） |
| **情報** | 通常の案内・進捗・空状態・ヒント・ラベル（エラーではない） |

## 1. エラー一覧

| ID | 文言（またはパターン） | 表示場所 / 条件 |
|----|------------------------|-----------------|
| E-01 | 検索に失敗しました。 | サイドバー上部（検索実行で例外発生時） |
| E-02 | 対象フォルダを設定してください。 | フッター（再構築／差分更新を試みたが検索対象フォルダが未設定） |
| E-03 | 差分更新に失敗しました。 | フッター（差分更新の例外時。続けて `ex.Message` が付く場合あり） |
| E-04 | インデックス構築に失敗しました。 | フッター（全体再構築の例外時） |
| E-05 | `[エラー] {例外メッセージ}` | プレビュー領域 1 行（`PreviewService` の抽出失敗時） |
| E-06 | `[エラー] {例外メッセージ}` | プレビュー領域 1 行（`Home.Preview.cs` の `LoadPreview` catch。`UserMessages.PreviewErrorLine`） |

※ E-05/E-06 の `{例外メッセージ}` は実行環境・ファイル内容に依存する。

## 2. 警告一覧

| ID | 文言（またはパターン） | 表示場所 / 条件 |
|----|------------------------|-----------------|
| W-01 | 再構築中は検索できません。 | サイドバー検索欄上（インデックス構築中） |
| W-02 | フォルダパスを入力してください | 設定モーダル（手動「追加」で空のとき） |
| W-03 | フォルダが見つかりません。パスを確認してください。 | 設定モーダル（手動追加でパスが存在しないとき） |
| W-04 | 既に追加されています | 設定モーダル（フォルダまたは拡張子の重複追加時） |
| W-05 | フォルダの選択に失敗しました: {例外メッセージ} | 設定モーダル（`FolderPicker` 等で例外時） |
| W-06 | `{N} 件がスキップされました`（`{N}` は `N0` 区切り） | フッター（インデックス完了後、スキップが 1 件以上あるとき。警告色の行をクリックでスキップログを開く） |

※ スキップしたファイルのパス一覧はインデックス保存先の `skipped_files.log` に出力される（UI ではパスは表示せず、上記の行クリックで開く）。

## 4. ファイル出力・ログ（ユーザーが参照する補助情報）

| 種類 | 内容 |
|------|------|
| `skipped_files.log`（インデックスディレクトリ内） | 1 行目: `スキップファイル一覧 - yyyy-MM-dd HH:mm:ss`、2 行目: `合計: N 件`、空行のあとスキップしたファイルパスを 1 行 1 パス。文言は **`FullTextSearch.Core.IndexMessages`**（`SkippedLogHeaderLine` / `SkippedLogTotalLine`）で `LuceneIndexService` が出力 |

インデックスの **filetype フィールド**（拡張子に応じた表示名: Word文書、PDFファイル等）は同じく **`IndexMessages.GetFileTypeDisplayName`** に集約している。

|----|------|------|

## 7. 文言を変えたあとに確認すること（チェックリスト）

1. **`UserMessages` / `IndexMessages`** の定数・ヘルパーを編集したら、本ドキュメントの該当 ID を更新する。
2. **`wwwroot/index.html`** の `<title>`・読み込み中・エラー帯は静的 HTML のため、**`UserMessages.AppTitle` / `PreviewLoading` / `WebViewLoadError` / `WebViewReload` と手で揃える**（ファイル先頭の HTML コメント参照）。
3. **`FileSearch.Blazor.csproj`** の `ApplicationTitle` は `UserMessages.AppTitle` と同じ文言にする。
4. **`dotnet build` と `dotnet test`** で問題ないことを確認する。
5. （任意）リポジトリルートで **`pwsh -File scripts/check-webview-strings.ps1`** を実行する。配布用 ZIP を作る **`scripts/build-dist.bat`** / **`build-dist.ps1`** は publish の前に同スクリプトを実行する。
