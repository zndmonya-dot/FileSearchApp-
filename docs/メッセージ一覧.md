# メッセージ一覧（エラー・警告・情報）

ユーザー向けに画面やログに表示される文言を分類して一覧化する。文言変更・多言語化・テスト設計の参照用。

**凡例**

| 分類 | 意味 |
|------|------|
| **エラー** | 操作の失敗や致命的な問題を示す（バナー・フッター赤字・`[エラー]` 接頭辞など） |
| **警告** | 続行可能だが注意が必要（設定バリデーションの黄枠・スキップ件数・インデックス中の制限など） |
| **情報** | 通常の案内・進捗・空状態・ヒント・ラベル（エラーではない） |

---

## 1. エラー一覧

| ID | 文言（またはパターン） | 表示場所 / 条件 |
|----|------------------------|-----------------|
| E-01 | 検索に失敗しました。 | サイドバー上部（検索実行で例外発生時） |
| E-02 | 対象フォルダを設定してください。 | フッター（再構築／差分更新を試みたが検索対象フォルダが未設定） |
| E-03 | 差分更新に失敗しました。 | フッター（差分更新の例外時。続けて `ex.Message` が付く場合あり） |
| E-04 | インデックス構築に失敗しました。 | フッター（全体再構築の例外時） |
| E-05 | `[エラー] {例外メッセージ}` | プレビュー領域 1 行（`PreviewService` の抽出失敗時） |
| E-06 | `[エラー] {例外メッセージ}` | プレビュー領域 1 行（`Home` のプレビュー取得で例外が別経路で発生した場合） |

※ E-05/E-06 の `{例外メッセージ}` は実行環境・ファイル内容に依存する。

---

## 2. 警告一覧

| ID | 文言（またはパターン） | 表示場所 / 条件 |
|----|------------------------|-----------------|
| W-01 | 再構築中は検索できません。 | サイドバー検索欄上（インデックス構築中） |
| W-02 | フォルダパスを入力してください | 設定モーダル（手動「追加」で空のとき） |
| W-03 | フォルダが見つかりません。パスを確認してください。 | 設定モーダル（手動追加でパスが存在しないとき） |
| W-04 | 既に追加されています | 設定モーダル（フォルダまたは拡張子の重複追加時） |
| W-05 | フォルダの選択に失敗しました: {例外メッセージ} | 設定モーダル（`FolderPicker` 等で例外時） |
| W-06 | 1行目: `{N} 件のファイルをスキップ` — 2行目: `ログ: {パス}`（長いパスは折り返し。ブロック全体に `title` で全文） | フッター（インデックス完了後、スキップが 1 件以上あるとき。警告色） |

※ W-06 の `{パス}` は `skipped_files.log` の保存先（`IndexService.LastSkippedLogPath`）。旧仕様の 1 行連結文言は廃止。

## 3. 情報一覧

### 3.1 検索・結果ツリー

| ID | 文言 | 条件 |
|----|------|------|
| I-01 | キーワードで検索（Enter） | 検索ボックスのプレースホルダ |
| I-02 | 検索キーワードを入力 | ツリー空でキーワード未入力 |
| I-03 | Enter で検索 | ツリー空でキーワードあり・まだ検索未実行 |
| I-04 | 結果なし | 検索実行済みでヒット 0 |
| I-05 | 検索中... | 検索実行中 |

### 3.2 インデックス進捗・フッター（正常時）

| ID | 文言（またはパターン） | 条件 |
|----|------------------------|------|
| I-10 | 構築中 `{N}%` | インデックス構築中のフッター主行 |
| I-11 | `{処理数} / {合計} ファイル` または `{処理数} / {合計} 件` | 進捗テキスト（現在ファイル名があればファイル名のみ表示の場合あり） |
| I-12 | `{処理数} / {合計} {単位}（スキップ {M} 件）` | 進捗中にスキップが発生したとき（エラーではなく進捗表示） |
| I-13 | 差分を検出中... | 差分更新の初期メッセージ |
| I-14 | 準備中... | 全体再構築の初期メッセージ |
| I-15 | キャンセルしました | ユーザーがキャンセルして正常終了したときの進捗行 |
| I-16 | `{N} 件登録済み` | フッター（インデックス件数） |
| I-17 | `{相対時間または日時} に更新` | フッター（`DisplayFormatters.FormatLastIndexUpdate` ベース） |
| I-18 | 未実行 | 最終更新がないとき（フォーマッター／設定の「最終更新」欄） |
| I-19 | たった今 / `{n}分前` / `{n}時間前` / `{n}日前` / `MM/dd HH:mm` | 最終更新の相対・短い日時表示 |

### 3.3 プレビュー

| ID | 文言 | 条件 |
|----|------|------|
| I-20 | ファイルパスが指定されていません | プレビュー API にパスが空（通常は UI からは起きにくい） |
| I-21 | `[プレビュー不可]` | 対応拡張子の抽出器がないときの本文プレースホルダ |
| I-22 | `[キャンセル]` | プレビュー処理がキャンセルされたとき |
| I-23 | 読み込みをキャンセルしました | `Home` 側でプレビュー読み込みをキャンセルしたとき |
| I-24 | `... (省略)` | プレビュー本文が `PreviewMaxChars` を超えた末尾 |
| I-25 | `{バイト}` B / KB / MB | 一覧のファイルサイズ（`FormatSize`） |
| I-26 | `yyyy/MM/dd HH:mm` | 一覧の日付（`FormatDate`） |

## 4. ファイル出力・ログ（ユーザーが参照する補助情報）

| 種類 | 内容 |
|------|------|
| `skipped_files.log`（インデックスディレクトリ内） | 1 行目: `スキップファイル一覧 - yyyy-MM-dd HH:mm:ss`、2 行目: `合計: N 件`、空行のあとスキップしたファイルパスを 1 行 1 パス |

---

## 5. 開発者向け（通常は UI に出さない）

アプリ利用者にはそのまま表示しないが、コード・例外・ログで使う英語メッセージ。

| 場所 | 文言 |
|------|------|
| `LuceneIndexService.EnsureInitialized` | `IndexService has not been initialized. Call InitializeAsync first.` |
| 抽出器（ファイル不存在時など） | `File not found` 等（英語、`FileNotFoundException`） |
| `TextFileExtractor` | `File is too large: {size} bytes` |
