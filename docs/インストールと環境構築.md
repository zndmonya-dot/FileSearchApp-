## 1. インストール手順（利用者向け）

**対象**: 配布された **.msix** と **.cer** を受け取り、PC にアプリを入れて使う人。

**不要なもの**: Python / Rust のインストール（配布版に `sudachi_ffi.dll` と辞書が同梱される）。

**手順の全体像**:

1. **.NET 8 デスクトップ ランタイム**が未導入ならインストール（MSIX 実行時に案内される場合あり）。
2. **証明書（.cer）** を「信頼されたルート証明機関」に追加する（初回のみ。GUI または PowerShell）。
3. **.msix** をダブルクリックしてアプリをインストールする。
4. 起動後、**設定**で検索対象フォルダを追加し、**再構築**でインデックスを作成する。

**詳細（コマンド例・トラブルシュート含む）**は **[社内配布手順.md](社内配布手順.md)** の「利用者向け：インストール手順」を参照する。

利用中の操作は **[操作マニュアル.md](操作マニュアル.md)** を参照する。

## 2. 環境構築手順（開発者向け）

**対象**: 本リポジトリを clone し、**ビルド・実行・デバッグ**する人。

### 2.1 必要な環境

| 項目 | 内容 |
|------|------|
| OS | Windows 10 / 11（64bit） |
| .NET | **.NET 8 SDK**（[ダウンロード](https://dotnet.microsoft.com/download/dotnet/8.0)） |
| Rust | **stable**（Sudachi ネイティブ DLL の初回ビルド用。`dotnet build` 時に DLL が無ければ自動実行） |
| IDE | 任意（Visual Studio 2022 / VS Code / Rider 等） |

※ 検索・プレビューで Office をインストールする必要はない（テキスト抽出のみ）。ファイルを「開く」操作で Office が使われる場合がある。

### 2.2 Sudachi ネイティブ（初回のみ）

初回 `dotnet build` 時、`scripts/build-sudachi-native.ps1` が Sudachi core 辞書（約 70MB）を取得し `sudachi_ffi.dll` をビルドする。手動で行う場合:

```powershell
pwsh -File scripts/build-sudachi-native.ps1
```

### 2.3 取得とビルド

```powershell
cd C:\全文検索システム
git clone <リポジトリURL>   # 未入手の場合
dotnet restore
dotnet build
```

### 2.4 実行（デバッグ）

```powershell
dotnet run --project src\FileSearch.Blazor
```

ターゲットフレームワークは環境により `net8.0-windows10.0.x` 等が指定される。ビルドエラー時は SDK のワークロード（.NET MAUI 等）が入っているか確認する。

### 2.5 MSIX の再作成（配布用ビルド）

Release ビルド後、出力フォルダに **.msix** が生成される。手順・証明書・配布物のまとめ方は **[社内配布手順.md](社内配布手順.md)** の「配布者向け」を参照する。

### 2.6 注意

- **アナライザ（Sudachi）や Lucene のフィールド定義を変えた**場合、既存インデックスと互換がなくなることがある。そのときはアプリ内で **全体を再構築**する。
- リポジトリ直下の [README.md](../README.md) にも概要・プロジェクト構成がある。

## 3. 用語の対応

| 用語 | 意味 |
|------|------|
| **インストール** | 利用者が **MSIX（または配布物）を PC に入れてアプリを使える状態にする**こと。 |
| **環境構築** | 開発者が **SDK・言語ランタイム・依存関係をそろえ、ソースからビルド・実行できる状態にする**こと。 |

両方とも「セットアップ」と呼ばれることがあるが、本ドキュメントでは上記のように区別する。
