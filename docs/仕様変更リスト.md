# 仕様変更リスト（2026年5月下旬以降）

5月下旬時点のコードベース（直前の安定版は **2026-04-26** `70385f8` 付近。5月のコミットはなし）からの仕様変更をまとめる。

**網羅的な変更履歴**はルートの [仕様変更まとめ.md](../仕様変更まとめ.md) を参照すること。

---

## 1. 検索機能

### 1.1 検索モードの追加（2026-06-07）

| モード | UI表示 | 挙動 |
|--------|--------|------|
| AND検索 | デフォルト | スペース区切りの各語を**すべて**部分一致 |
| OR検索 | 新規 | スペース区切りの**いずれか**を部分一致 |
| 完全一致検索 | 新規 | 入力文字列が**連続してそのまま**含まれる（バイグラムで候補絞り込み） |

- サイドバーにラジオボタンで切替
- プレビューのハイライトもモードに追従

### 1.2 検索UI（2026-06-12〜18）

- **検索ボタン**を追加（Enter でも検索可）
- プレースホルダを「**キーワードを入力…**」に統一
- **モード切替時**: キーワードがあれば自動再検索、スピナー表示、再検索中はモード切替を無効化
- 検索中はツリー内に **CuteLoader（スピナーのみ）**。`（n/N 件）` 進捗・サイドバー件数バッジは廃止（6/19 以降）

## 2. 共有インデックス・管理者／非管理者（2026-06-12）

### 2.1 `appmode.json`（実行ファイル横）

| キー | 説明 |
|------|------|
| `mode` | `admin` / `reference` 等（管理者か参照専用か） |
| `sharedConfig` | サーバ上 `shared.json` の UNC パス |
| `forceNonAdmin` | UI確認用。本番は省略または `false` |

### 2.2 管理者判定

- **ローカルアカウント**（ユーザーのドメイン名＝PC名）→ 管理者
- **ドメインアカウント**（AD）→ 非管理者（参照専用）

### 2.3 非管理者の権限

| 項目 | 可否 |
|------|------|
| 検索・プレビュー | 可 |
| インデックス再構築・自動更新 | 不可 |
| 設定: フォルダ・インデックスパス・自動更新 | 閲覧のみ（非活性） |
| 設定: テーマ・対象拡張子 | 個人設定として保存可 |

### 2.4 拡張子（非管理者）

- `settings.json` の `TargetExtensions` は**個人設定**
- 検索時に結果を post-filter（共有インデックス本体は変更しない）

### 2.5 インデックス参照

- 非管理者は `InitializeAsync(readOnly: true)` … IndexWriter を開かない
- 初回起動で `TargetFolders` が空のとき、`shared.json` のフォルダ適用または検索結果からツリー自動推定

### 2.6 `shared.json`（2026-06-17〜18）

- 管理者の設定保存で `indexPath` + `targetFolders` を自動書き込み
- `appmode.json` の `sharedConfig` は **起動時に読み込み**。変更追従は **アプリ再起動**（60 秒ポーリングは 6/17 以降廃止）

## 3. 自動更新（定期差分更新）（2026-06-12〜）

| 設定 | 挙動 |
|------|------|
| `AutoRebuildDailyHours` | 日本標準時 **0〜23 時**のリスト。チェックした時刻枠を過ぎ、当該枠で未更新なら**差分更新** |
| 無効 | 時刻未選択（リスト空） |
| 旧 `AutoRebuildIntervalMinutes` | 読み込み時に上記へ移行 |

- UI: 「自動更新」チェック + JST 時刻グリッド（30分/1時間 等の間隔 UI は廃止）
- 非管理者は自動更新しない
- 検索操作から30秒以内は実行を見送り（従来どおり）

---

## 4. インデックス構築の性能（2026-06-12〜19）

他アプリ共存を優先し並列度を調整:

- Sudachi プール: `max(2, min(8, ProcessorCount/2))`（`SudachiTokenizer.PoolSize`）
- マージスレッド 1、優先度 BelowNormal
- RAM バッファ 256MB
- 構築中 ETA 表示（推定可能時）。**構築中はスキップ件数を非表示**（完了後フッターのみ）

---

## 5. 非管理者向けUI（2026-06-12）

- 非活性コントロールに `cursor: not-allowed`、グレーアウト
- 検索フォルダ: 削除ボタン非表示（参照専用バッジ）
- 設定セクションに「参照専用」バッジ

---

## 6. 設定 UI（2026-06-13〜18）

- 検索対象フォルダ・インデックス保存先: **フォルダピッカーアイコンのみ**（パス手入力・「追加」「参照」テキストボタン廃止）
- インデックス保存先は **1 フォルダのみ**指定
- フォルダ一覧: **名前 / 内容 / 更新日時** 列、エクスプローラー式リサイズ

---

## 7. その他（2026-06-14〜21）

- 起動時からフォルダツリー閲覧（検索前プレビュー可）
- ウィンドウタイトル: **`Panoleon v2.0`**（`AppVersion` で一元化）
- 起動スプラッシュ: テーマ連動、段階メッセージ、最低 **2.6 秒**表示
- サイドバー見出し: 常に **「全文検索システム」**
- インデックス更新ダイアログ: 2 カード横並び UI（進捗はフッター）
- 設定 **保存** / 更新 **実行** ボタン: 青系プライマリ
- **Esc**: 閲覧モードへ復帰（クエリ・結果・選択をクリア）
- 対象拡張子: **31 種**（`.doc`/`.xls` NPOI、`.ts`/`.json` 追加等）
- ファイルサイズ上限: 実行時は **`ContentLimits` の 1MB 固定**（`shared.json` の `indexMaxFileBytes` は JSON 例のみ・未読込）
