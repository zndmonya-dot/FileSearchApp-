# 仕様変更リスト（2026年5月下旬以降）

5月下旬時点のコードベース（直前の安定版は **2026-04-26** `70385f8` 付近。5月のコミットはなし）からの仕様変更をまとめる。

---

## 1. 検索機能

### 1.1 検索モードの追加（2026-06-07）

| モード | UI表示 | 挙動 |
|--------|--------|------|
| AND検索 | デフォルト | スペース区切りの各語を**すべて**部分一致 |
| OR検索 | 新規 | スペース区切りの**いずれか**を部分一致 |
| 完全一致検索 | 新規 | 入力文字列が**連続してそのまま**含まれる（バイグラムで候補絞り込み） |

- サイドバーにラジオボタンで切替
- プレビューのハイライトもモードに追従

### 1.2 検索UI（2026-06-12〜13）

- **検索ボタン**を追加（Enter でも検索可）
- プレースホルダを「検索キーワードを入力」に統一
- **モード切替時**: キーワードがあれば自動再検索、スピナー表示、再検索中はモード切替を無効化

## 2. 共有インデックス・管理者／非管理者（2026-06-12）

### 2.1 `appmode.json`（実行ファイル横）

| キー | 説明 |
|------|------|
| `indexPath` | 共有インデックスのパス |
| `targetFolders` | クライアント初回起動時に検索フォルダへ反映（任意） |
| `forceNonAdmin` | UI確認用。本番は省略または `false` |

### 2.2 管理者判定

- **ローカルアカウント**（ユーザーのドメイン名＝PC名）→ 管理者
- **ドメインアカウント**（AD）→ 非管理者（参照専用）

### 2.3 非管理者の権限

| 項目 | 可否 |
|------|------|
| 検索・プレビュー | 可 |
| インデックス再構築・自動更新 | 不可 |
| 設定: フォルダ・インデックスパス・自動更新 | 閲覧のみ（非活性） |
| 設定: テーマ・対象拡張子 | 個人設定として保存可 |

### 2.4 拡張子（非管理者）

- `settings.json` の `TargetExtensions` は**個人設定**
- 検索時に結果を post-filter（共有インデックス本体は変更しない）

### 2.5 インデックス参照

- 非管理者は `InitializeAsync(readOnly: true)` … IndexWriter を開かない
- 初回起動で `TargetFolders` が空のとき、`appmode.json` のフォルダ適用または検索結果からツリー自動推定

## 3. 自動更新（定期再構築）（2026-06-12）

| 設定値 | 旧仕様 | 新仕様 |
|--------|--------|--------|
| 30分〜12時間 | 前回更新から N 分 | **変更なし**（経過時間） |
| 毎日0時（1440分） | 前回から24時間 | **日本時間の日付変更後**（午前0時以降） |
| 毎週月曜0時（10080分） | 前回から1週間 | **毎週月曜 0時（日本時間）** |

- UIラベル: 「自動更新」「毎日0時」「毎週月曜0時」
- 非管理者は自動更新しない
- 検索操作から30秒以内は実行を見送り（従来どおり）

---

## 4. インデックス構築の性能（2026-06-12）

他アプリ共存を優先し並列度を抑制:

- パイプライン並列 ≈ 4
- Sudachi プール最大 2
- マージスレッド 1、優先度 BelowNormal
- RAM バッファ 256MB

---

## 5. 非管理者向けUI（2026-06-12）

- 非活性コントロールに `cursor: not-allowed`、グレーアウト
- 検索フォルダ: 削除ボタン非表示、入力行非表示
- 設定セクションに「参照専用」バッジ

---

## 6. インデックス保存先UI（2026-06-13）

- **1フォルダのみ**指定（検索対象フォルダの一覧UIとは別レイアウト）
- パス入力欄に直接入力、または **フォルダを設定** で指定
- 設定画面の「フォルダを開く」（エクスプローラーで開く）は削除

## 7. 検索対象フォルダ・インデックス保存先UI（2026-06-13）

- パス手入力欄を廃止（**フォルダを設定** のみ）
- **追加**ボタンを廃止
- **参照** → **フォルダを設定** に名称変更
- 未登録時の空状態表示、パス表示のレイアウト統一
