# テスト用チェックリスト

本システムの動作確認用チェックリストです。要件定義書・外部設計書に基づき、テスト実施時に利用してください。

**記入例**: 合格は ✓ または ○、不合格は ✗ または ×、未実施は空欄。備考欄にバージョン・環境・不具合内容などを記入可。

## 6. 操作・キーボード・プレビュー操作

※ キーボードショートカットは **検索欄にフォーカスがあるときの Enter（検索）／Esc（クリア）** が主。ファイルを開く・フォルダを開くは **プレビュー上のボタン**。グローバルな Ctrl+Enter / Ctrl+C / Ctrl+F は **未実装**（要件定義・外部設計参照）。


| No. | 確認項目           | 期待結果                                    | 結果  | 備考  |
| --- | -------------- | --------------------------------------- | --- | --- |
| 6.1 | 検索欄で Enter     | 検索が実行される                                |     |     |
| 6.2 | 検索欄で Esc       | 検索クエリとエラーメッセージがクリアされる。結果一覧は残る場合がある      |     |     |
| 6.3 | プレビュー「開く」ボタン   | 関連アプリでファイルが開く                           |     |     |
| 6.4 | プレビュー「フォルダ」ボタン | エクスプローラーで該当ファイルの場所が開く（`/select` 相当）     |     |     |
| 6.5 | 初回表示時の検索欄フォーカス | ルーティング（FocusOnNavigate）により検索入力にフォーカスが移る |     |     |
| 6.6 | 検索結果の選択        | ツリーのファイルノードをクリックで選択でき、プレビューが表示される       |     |     |
| 6.7 | 左サイドバー上で **Ctrl + ホイール上**     | サイドバーのみ拡大される（右メイン領域はサイズ変化なし）       |     |     |
| 6.8 | 左サイドバー上で **Ctrl + ホイール下**     | サイドバーのみ縮小される       |     |     |
| 6.9 | 右メイン上で **Ctrl + ホイール**          | 右メインのみ拡大／縮小され、左サイドバーは変化しない       |     |     |
| 6.10 | サイドバー内で **Ctrl + 0**              | サイドバーのみ等倍に戻り、右メインの倍率は維持される       |     |     |
| 6.11 | 右メイン内で **Ctrl + 0**                | 右メインのみ等倍に戻り、サイドバーの倍率は維持される       |     |     |
| 6.12 | 倍率の上下限                              | 0.5 倍未満／3.0 倍超には変更されない（クランプされる）       |     |     |
| 6.13 | アプリ再起動 or WebView 再読み込み        | サイドバー・右メインともに等倍に戻る（倍率は永続化されない）       |     |     |
| 6.14 | ヘッダ／モーダル上での Ctrl + ホイール       | ページ全体ズームは発生せず、対象外なので領域ズームも発生しない       |     |     |
